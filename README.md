# مُنظِّم الدراسة الذكي

تطبيق ويب عربي يساعد الطالب على تنظيم موادّه ومهامه الدراسية ومتابعة تقدمه.

## المميزات
- إضافة المواد والمهام مع تاريخ التسليم
- ترتيب المهام حسب الأقرب موعدًا
- ألوان توضح المهام المتأخرة والقريبة من موعدها
- نسبة التقدم لكل مادة
- حفظ البيانات داخل المتصفح (IndexedDB) بدون خادم

## التقنيات
HTML و CSS و JavaScript و IndexedDB
